# AI Literacy for CS Faculty

A 20-minute AI literacy talk for the Fall 2026 CS faculty meeting, built with reveal.js. Four parts: the engine (one string, one loop; how a 2026 model is trained), the curve (METR time horizons, cost, context, recursive self-improvement, Genesis Mission / NAIRR / RAISE Act / EU AI Act), agents (the harness, prompt injection and the lethal trifecta), and the classroom (MIT's August 2026 report, what to grade, a live demo). It builds on the AI Committee's *AI Literacy Tutorial* draft.

Play online: https://aquastar.github.io/ai-literacy-faculty/

Keys: Space or arrows to advance, S for speaker notes (with timing cues), Esc for overview.
