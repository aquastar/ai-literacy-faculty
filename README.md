# AI Literacy for Faculty

A 20-minute AI literacy talk for the Fall 2026 faculty meeting, built with reveal.js. It goes from next-token prediction to chat, RLHF, reasoning, RAG, tool use, MCP, agents, RLVR, context windows, and multi-agent systems. It builds on the AI Committee's *AI Literacy Tutorial* draft.

Play online: https://aquastar.github.io/ai-literacy-faculty/

Keys: Space or arrows to advance, S for speaker notes (with timing cues), Esc for overview.
